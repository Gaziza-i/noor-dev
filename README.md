# noor.dev — портфолио веб-разработчика

Персональный сайт-портфолио. Лендинги, интернет-магазины, вёрстка по макету. Казань · удалённо.

**[🌐 Открыть сайт](https://gaziza-i.github.io/noor-dev/)**

![noor.dev preview](https://gaziza-i.github.io/noor-dev/cleaning-main-light.png)

## Стек

- Vanilla HTML / CSS / JS — без фреймворков
- Google Fonts: Syne + DM Sans
- IntersectionObserver — fade-up анимации
- Web Speech API (проект Voice2Text)
- CSS Custom Properties, адаптив

## Разделы

- **Hero** — заголовок с typewriter-эффектом, параллакс на карточке
- **Обо мне** — счётчики статистики
- **Навыки** — 12 технологий, SVG-иконки
- **Проекты** — 5 карточек, слайд-шоу превью, лайтбокс-галерея
- **Услуги и цены** — 4 тарифа
- **Контакт** — Telegram + email
